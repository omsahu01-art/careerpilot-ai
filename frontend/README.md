# CareerPilot AI 🚀

### AI-Powered Career & Skill Readiness Intelligence

CareerPilot AI is a career intelligence platform that helps students and job seekers understand their current skills, identify gaps for a target role, and follow a personalized roadmap toward career readiness.

Instead of simply parsing a resume or listing jobs, CareerPilot AI connects:

**Resume → Skills → Target Role → Alignment → Skill Gaps → Roadmap → Projects → Progress**

---

## 🎯 Problem

Students and early-career professionals often face a common problem:

- They know some technologies but don't know how well they match a target role.
- Resume skill lists don't clearly show what they are missing.
- Learning resources are scattered across different platforms.
- It is difficult to decide what to learn first.
- Completing courses does not always translate into practical projects.

CareerPilot AI addresses this by turning a resume into an actionable skill development journey.

---

## 💡 Solution

CareerPilot AI analyzes a user's resume, extracts relevant skills and supporting evidence, and compares those skills against requirements for a selected career role.

The system identifies:

- ✅ Matched skills
- 🟡 Partial skills
- 🔴 Missing skills
- 📊 Role Alignment Estimate
- 🧭 Personalized learning roadmap
- 🛠️ Recommended projects
- 📈 Progress tracking

The alignment score is an evidence-based estimate against the selected skill framework. It is **not a hiring prediction**.

---

# ✨ Key Features

## 1. Resume Understanding

Users can upload their resume in supported formats.

CareerPilot AI extracts relevant information such as:

- Skills
- Experience
- Projects
- Education
- Certifications

The current implementation supports PDF and DOCX resume processing.

---

## 2. Evidence-Based Skill Extraction

Instead of simply displaying a list of keywords, CareerPilot AI associates detected skills with supporting evidence.

Each detected skill can contain:

- Skill name
- Current level
- Confidence
- Resume evidence
- Source

Example:

```text
Python
Level: Intermediate
Confidence: 90%
Evidence: Built data analysis and automation projects using Python.
Source: Resume
